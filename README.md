**overview**
The project predicts the species of an iris using various measurememnts sepal length sepal width petal length petal widt

**Algorithm**
KNN Neighbors(KNN)

**Dataset**
The built-in dataset contains 150 samples and 4 features

**Tools**
python,Scikit learn

**workflow**

1.Load the dataset.
2.Split the dataset into two as training and testing.
3.Training=80%,Testing=20%.
4.use the KNN model.
5.Evaluate the accuracy and confusion matrix.
6.predict the species with new measurements.
